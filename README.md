# Coastal Satellite Hub / Central de Aplicativos do Litoral

[Open the direct HTTPS hub](https://saipradikmallakuntla-tech.github.io/praia-digital-satellite-hub/)

PT/EN directory of six independent coastal utilities. Six category filters, municipality filters, safe allowlisted app links, zero-match/reset states and ordinary HTML navigation to every satellite. Filters describe documentary coverage or fictional examples, not operational availability. Three original apps keep their Portuguese interfaces and existing logic; the new three apps and hub support PT/EN.

Static local HTML/CSS/JS, no build, dependency, analytics, backend, custom domain or CNAME file. Serve with `python3 -m http.server 8080`. GitHub Pages: `main` root, `.nojekyll`, HTTPS enforced. `?lang=en` selects English. Network links work without JavaScript.

- [Architecture](SATELLITE_NETWORK_ARCHITECTURE.md)
- [Network URL policy](NETWORK.md)
- Release evidence: `DIRECT_PAGES_NETWORK_RELEASE.md` is absent from the inspected `main` snapshot of 2026-11-16. Evidence remains unavailable; this README is not a verified release or test receipt.

New utility datasets are explicitly fictional/reference-only. No current water-quality, verified cycling route or real market/service schedule is asserted. External links are contextual references, not an affiliation or an upstream integration.

### Retorno e relação com a rede

Nos aplicativos, o rótulo documental comum para este endereço é **Central de apps**. Nesta central não adicionar auto-retorno. Os links entre aplicativos são troca de propriedade independente, não uma trilha que os transforme em filhos do site Praia Digital. O [hub de apps da produção](https://praia.digital/apps/) é uma identidade distinta, sem integração, afiliação institucional ou compartilhamento de registros presumidos.

### Idioma e cobertura

A central oferece PT/EN; os três aplicativos originais deste recorte mantêm interface PT. Filtros de município/categoria descrevem referências ou exemplos, não disponibilidade de operação. Não prometer tradução universal ou dados em tempo real.

### Limites editoriais

Preservar fontes, datas, desconhecidos e exemplos fictícios. Maresia não é laudo nem sincronização automática; Acesso não garante acessibilidade ou operação atual; Costa não certifica segurança de lotes nem emite alerta atual. Os projetos compartilham a origem github.io; armazenamento local não constitui isolamento entre aplicativos. O relatório de publicação ausente permanece uma pendência, não prova reconstruída.
