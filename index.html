Conexões simples, limites claros

Cada app funciona por conta própria.

Todos os sete sites têm links HTML para os outros seis: 42 caminhos direcionados, sem login compartilhado ou roteador central. Os novos apps e esta central oferecem PT/EN; os três originais preservam interface PT e lógica.

Sem APIs em tempo real. Os caminhos github.io compartilham a mesma origem; armazenamento local não é uma barreira de isolamento entre apps.
